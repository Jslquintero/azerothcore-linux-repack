AzerothCore — repack offline para Linux x86_64

Requisitos: Docker Engine con Compose v2, Bash, tar y sha256sum.
El asistente crear-cuenta.sh usa Python 3; sin Python puedes usar console.sh.
Necesitas además tu cliente WoW 3.3.5a (12340). No está incluido.
Reserva al menos 30 GB libres para descomprimir, cargar imágenes y guardar partidas.

1. Ejecuta ./instalar.sh. No necesita Internet ni compilar el servidor.
2. Espera a que el worldserver esté listo en ./logs.sh.
3. Ejecuta ./crear-cuenta.sh e introduce el nombre y la contraseña.
   También puedes usar ./console.sh; sal con Ctrl+P, Ctrl+Q.
4. Copia client/patch-z.mpq en Data del cliente y la carpeta
   client/AcoreRacialTooltips en Interface/AddOns. Reinicia el cliente.
5. Configura el realmlist: set realmlist 127.0.0.1

Después: ./start.sh para jugar y ./stop.sh para detener el servidor.
La primera inicialización tarda varios minutos; los bots generan sus cachés.
Se incluyen 100 bots como preset para juego local, configurable en compose.json.

Las cuentas y partidas se guardan en volúmenes Docker del proyecto acore-offline.
No ejecutes docker compose down -v: borraría esos datos.
No cambies COMPOSE_PROJECT_NAME después de instalar: apunta a otros volúmenes.
Reejecutar el instalador de esta misma versión conserva los datos.
No se admiten actualizaciones automáticas entre versiones todavía: no sustituyas
una instalación existente por otro paquete sin respaldo y migración de la base.

La base inicial incluye el contenido del mundo y estructuras vacías de cuentas
y personajes. Playerbots se inicializa desde SQL, sin copiar cuentas existentes.
MySQL no publica puertos. Auth y world se publican únicamente en 127.0.0.1.
Para LAN hace falta configurar los puertos publicados y la dirección del realm.
Este paquete no instala Docker ni incluye el dashboard opcional.
